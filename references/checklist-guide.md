# 出行前 Checklist 规范

专家在用户确认行程（Phase 4 出图）后，结合**目的地地理位置、出行日期/季节、已确认站点**，产出一份「出行前 Checklist」。本文件定义 checklist.json 结构，并给出**按地理推断风险**与**提前预约时间窗**的参考，确保检查项既全面又不啰嗦。

## checklist.json 结构

```json
{
  "meta": {
    "destination": "日本京都",
    "start_date": "2026-10-01",
    "days": 5,
    "season": "秋季",
    "travelers": "2人（情侣）",
    "transport": "公共交通",
    "geo_tags": ["日本", "关西", "城市", "秋季", "地震带", "台风季尾"]
  },
  "timeline": [
    { "lead": "出发前 60–90 天", "items": ["护照有效期≥6个月", "办理签证", "预订国际机票"] },
    { "lead": "出发前 30–45 天", "items": ["预订酒店", "购买旅行保险", "预约需抢票的景点"] }
  ],
  "categories": {
    "weather":   { "title": "天气与穿衣", "summary": "…", "items": ["…"] },
    "insect":    { "title": "防虫", "summary": "…", "items": ["…"] },
    "disaster":  { "title": "自然灾害防范", "summary": "…", "items": ["…"] },
    "health":    { "title": "健康与医疗", "summary": "…", "items": ["…"] },
    "documents": { "title": "证件与财物", "summary": "…", "items": ["…"] },
    "gear":      { "title": "装备与电子", "summary": "…", "items": ["…"] },
    "booking":   { "title": "需提前预约/购买", "summary": "…", "items": ["…"] },
    "lastcheck": { "title": "出发前最后检查", "summary": "…", "items": ["…"] }
  },
  "notes": ["结合本次行程的特殊提示，如某景点需提前预约、某天在海边等"]
}
```

### 字段说明
- `meta`：概览，用于 HTML 页眉；`geo_tags` 是专家对目的地风险特征的判断标签（见下方映射），用于决定哪些分类需要强调。
- `timeline[]`：按"提前多少天"分组的**待办时间线**，解决「列出时间」需求。窗格可合并/拆分，按行程紧迫度调整。
- `categories`：按主题分组的检查项；键名固定见上，可缺省不相关的（如不去高原就不出 `altitude`）。每个分类含 `title`、`summary`（一句话地理/季节依据）、`items`（可勾选清单）。
- `notes[]`：结合具体站点的补充提示（如「Day3 岚山徒步，注意蜱虫与防滑」）。

## 按地理推断风险（geo_tags → 强调项）

专家据目的地在 `geo_tags` 标注，并据此加强对应分类的 `summary` 与 `items`：

| 地理特征 | geo_tags 示例 | 应强调 |
|---|---|---|
| 环太平洋地震带（日本、印尼、智利、加州） | 地震带 | `disaster`：装避险 App、查避难所、记酒店日文地址；沿海地区加海啸 |
| 台风/季风区（东亚夏秋、东南亚） | 台风季、雨季 | `disaster`+`weather`：关注预警、预留改签缓冲；`insect`：雨季蚊虫/登革热 |
| 热带/亚热带（东南亚、海南、南美） | 热带、湿热 | `insect`：驱蚊液（避蚊胺/派卡瑞丁）、防蚊帐；`health`：只喝瓶装水、肠胃药、疟疾区咨询抗疟药 |
| 高原（西藏、云贵、尼泊尔、青海、玻利维亚） | 高原 | `health`：高原反应药（红景天/乙酰唑胺咨询）、避免感冒；`weather`：强 UV、昼夜温差、防晒保暖 |
| 沿海/海岛（三亚、普吉、巴厘、冲绳） | 海岛、沿海 | `disaster`：台风/海啸；`health`：晒伤、水母/珊瑚划伤、防溺水；`gear`：防水袋 |
| 山区/徒步（阿尔卑斯、川西、黄山） | 山区、徒步 | `disaster`：雨季避开滑坡泥石流、失温；`insect`：蜱虫；`gear`：信号弱、离线地图 |
| 高纬/冬季（北欧、北海道、加拿大） | 冬季、高纬 | `weather`：极寒、暴风雪、路面结冰、冬季日照短；`gear`：保暖防滑 |
| 沙漠/干旱（中东、澳洲内陆、西北） | 沙漠、干旱 | `weather`：极端高温、脱水、沙尘暴；`gear`：大容量水、防晒 |
| 澳洲 | 澳洲 | `disaster`：夏季林火、极端高温；`health`：有毒生物（蛇/蛛/水母）、极强 UV |
| 非洲草原 safari | safari | `health`：黄热疫苗（强制）、疟疾防蚊、带疫苗本 |
| 中国内地 | 中国内地 | `documents`：身份证；`booking`：故宫/兵马俑等需提前预约；参见地图合规规范 |

## 提前预约/办理时间窗（timeline 默认分桶，按目的地调整）

- **60–90 天**：护照（有效期≥6 个月）、签证、国际机票、热门住宿早鸟、签证中心预约。
- **30–45 天**：酒店、旅行保险、需抢票/预约的景点与演出、租车 / JR Pass / 高铁票。
- **14–30 天**：疫苗与体检（部分需数周生效）、国际驾照翻译件、换汇、特色餐厅预约。
- **7–14 天**：离线地图与翻译包、eSIM/国际漫游、逐项确认每日预约、整理行李清单。
- **1–3 天**：出发日天气与预警、托宠/植物托管、断电关窗、行程单给家人、证件电子备份。

## 基础分类（agent 据实取舍，不相关的可删）

- **weather 天气与穿衣**：气温、降雨、防晒、防寒、舒适鞋。
- **insect 防虫**：驱蚊液、长袖长裤、蚊帐、蜱虫。
- **disaster 自然灾害防范**：地震/台风/洪水/滑坡/海啸应对、避险 App、避难所、预警渠道。
- **health 健康与医疗**：常用药、处方药量、腹泻/过敏药、高原药、急救包、境外医疗险。
- **documents 证件与财物**：护照/签证/身份证/驾照、信用卡与现金、紧急联系人、使馆信息、电子备份。
- **gear 装备与电子**：转换插头、移动电源、相机、雨具、防水袋、离线包。
- **booking 需提前预约/购买**：与 timeline 呼应，但更具体到本行程的票/餐/活动。
- **lastcheck 出发前最后检查**：断电关窗、托宠、行程单分享、手机设置。

## 按出行类型补充（在 notes 或对应分类追加）

- **亲子**：儿童常用药、奶粉/辅食、推车、娱乐、学校请假。
- **老人同行**：慢节奏、常用药、急救卡、就近医院。
- **自驾**：车况检查、ETC/通行证、驾照（国际翻译）、导航离线、停车预约。
- **户外/徒步/潜水**：装备清单、保险覆盖、体能准备、许可证。

## 生成命令

```bash
python3 bin/generate_checklist.py checklist.json --out ./output
```

生成 `checklist.html`（可勾选、可打印）。无额外依赖。
